# 局内服务界面重做

五个档口固定保留名称与菜系图案。每把实际工作的勺子对应一个圆环，环内显示该勺第一道菜；备菜完成后圆环变红，随后抛菜。同勺追加食材仍按实际权重随机抽取。点击档口或 Tab 打开暂停式指南，说明触手分配、现有菜谱、容量、价值和解锁等级。指南不改变现有掉落数值。

梁阿姨的表演层移到柜台横梁前，盘中食材仍在她前方。计时饭票位于左上；右侧账板独立容纳收入、均衡构成、深度思考圆形仪表与六项被动状态。信息条固定边界，数值与说明各占自己的空间；思考剩余时间、按键提示和冷却状态始终相邻。公告与招牌放在食物后面，不遮挡饭盒接菜。

指南关闭后不会占有局内操作焦点；Tab 在 GUI 焦点导航前响应。模态内部按钮有闭合导航，Esc / P / 手柄 B 关闭；世界计时暂停，思考/音效中断，恢复时保留防误触间隔。系统失焦不会在指南上再叠一层暂停。

专项测试 `canteen_presentation_test.tscn` 使用独立测试存档，覆盖早期/全部档口、全部被动效果、思考/冷却、逐档鼠标浏览、Tab/ESC、指南不叠加、关闭后的 Enter 送餐、图像实际尺寸、标签边界、公告与饭盒同位。测试发现并修复了图片最小尺寸覆盖90px约束、相邻招牌重叠、分钟边界倒计时和指南抢占 Enter 的问题。最终证据以统一 `pipeline/validate_release.py --visual` 的源码哈希、原尺寸截图和报告为准。
