# 饭桌后的大肥鱼：专属动作设计 + 饭盒循环重做

> 2026-10-16。右下角的大肥鱼是游戏的小卖点：她要像在「跟玩家一起上班」，每个动作都对应一件正在发生的事，玩家余光一扫就知道她现在要什么。

## 1. 新的饭盒循环（玩家提的方案）

```
饭桌：[空饭盒一摞]  [等着开吃的满饭盒队列]  大肥鱼(正在吃的一盒)
   玩家：从空饭盒摞上拿一个 → 去接 → 放回饭桌（进满饭盒队列）
   大肥鱼：从满饭盒队列取一盒 → 吃完 → 把空盒放回空饭盒摞
   小模型（外包）：也从空饭盒摞拿盒子，在地上跑着接，满了自己送回满饭盒队列
```
- 开场：所有饭盒叠在饭桌上，玩家手里是空的。点空饭盒摞（或手移到饭桌上按左键 / A）拿一个
- 端着满饭盒到饭桌上按左键 = 放下；端着空饭盒也能放回摞上
- 空饭盒叠成一摞，摞的高度就是数量；满饭盒在桌上排队
- 「再来一盒」照旧是多一个饭盒
- 「帮我做个 App」的外卖盒直接进满饭盒队列，吃完就没了（不是你的盒子）

## 2. 饭盒升级：2×2 → 2×3 → 2×4
- 行数固定 2 行，「大一号的饭盒」加的是列：更宽，接的范围（碰撞宽度）跟着变宽，容量 4 → 6 → 8
- 美术：2×3、2×4 由 2×2 的图在中间重复格子拼出来（和之前拼 4×4 一样，风格完全一致）

## 4. 大肥鱼的专属动作（按游戏状态）

她的专属餐具是**铁盆**（不是便当盒）：吃饭时端着铁盆对着便当盒往嘴里扒。

| 游戏状态 | 动作 | 表情 | 音效 |
|---|---|---|---|
| 开场、饭桌上没满饭盒 | 端着空铁盆眼巴巴望着玩家，左右晃 | 期待（睁眼） | — |
| 等了 4 秒还没饭 | **用勺子敲铁盆**（咚咚咚，越等越快） | 可怜 → 噘嘴 | 铁盆敲击声 |
| 等了 10 秒以上 | **把空铁盆扣在头上生闷气**，鼓腮帮子 | 噘嘴 | 「哼」+ 扣盆声 |
| 满饭盒放上桌 | 一下子把铁盆从头上拿下来，蹦起来 | 惊喜 → 张嘴 | 「哇」 |
| 猛炫 | 端起铁盆对着饭盒扒饭，头一点一点 | 张嘴 ↔ 嚼（鼓腮） | 咀嚼 |
| 吃到鸡腿 / 金饭团 | 停下来闪闪眼，晃一下 | 星星眼 / 开心 | 闪光 |
| 吃到青菜 | 噘嘴摇头，把青菜「呸」出去 | 噘嘴 | 呸 |
| 中午吃什么（暴击） | 停住托腮想一下，然后一大口 | 思考 → 开心 | 暴击 |
| 吃完一盒 | 把空饭盒往空饭盒摞上一放，拍拍肚子 | 满足 | 放盒子 |
| 玩家把吃的洒了 / 掉地上 | 「啊！」看过去 | 惊讶 | — |
| 深度思考（玩家按住） | 头顶冒思考泡泡，眼睛往上看 | 思考 | — |
| 吃饱了 | 往后一靠，肚子圆起来，打个嗝 | 犯困 | 打嗝 |
| 食堂关门（没吃饱） | 敲铁盆抗议，然后可怜巴巴 | 可怜 | 敲盆 |
| 试炼：服务器繁忙 / 宕机 | 头冒汗 / 转圈圈 | 惊讶 / 晕 | — |
| 一顿里越吃越多 | **肚子一点点变圆**（网格变形，不用新图） | — | — |
