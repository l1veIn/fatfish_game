# 档口布局、输入与图标更新验收 · v0.4.2 · 2026-10-20

本轮基于 `d60c9b4`，保留暖色食堂、小黑板、木档口、搪瓷乘区和软木板技能树。交互与局部表现的改动如下。

- 技能已有购入的直接下游时，退款至少保留1级；高于1级的部分仍可按原购买价格退还。未揭晓的下一层显示空白便签，不提前暴露技能内容。
- 深度思考取消蓝色落点标记，减速、冷却、能量和其他技能联动保留。
- Esc → 档口指南可以左右换位、恢复默认，并立即保存。移动的是原档口，备菜进度、菜品、勺子数与产量不变；已经飞出的食物不瞬移。完成3顿、至少开2档后提示一次。旧档使用默认位置，保存失败会恢复原排列。
- 设置 → 游戏新增键盘与手柄改键，覆盖移动、拿盒/送饭、思考、开饭和退款。支持按键、手柄按钮；移动与思考还支持轴方向/扳机。固定菜单导航、确认、返回、暂停保留。改键需要松开输入后才保存，冲突会说明，失焦或取消不提交。
- 技能树用 Back / Select 在地图与工具栏之间切换，B返回地图；键盘可用Tab进入工具栏。教学、说明书和思考HUD使用当前绑定提示。
- 小助手脚下的文字改为职责、目标菜品和状态图标；分工面板复用相同图形并给出图例，不修改助手的行为与收益。
- 黑屏启动Logo、窗口和Windows图标使用“头扣铁盆、面无表情的大肥鱼”。原图、实际提示词与机械转码记录见 [制作记录](../art_src/brand/README.md)。标题页艺术字不变。

## 验证方式

使用 Godot 4.7.2 与独立QA档案。玩家的 `save.json`、`save.json.bak`、`settings.cfg` 在回归和导出运行前后校验哈希。指定 `--test-profile` 时，测试设置也隔离在 `qa_<profile>_settings.cfg`，不读取玩家改键配置。

广泛回归命令为 `python pipeline/validate_release.py --visual --runs 12 --uncapped-ui --ui-timeout 300`。实际窗口场景记录完整命令，使用 `--disable-vsync --max-fps 120` 请求加快截图；场景内应用设置仍可能重新改变VSync。这些结果不用于性能评级。测试过程中冻结游戏源码，报告包含前后哈希。

范围包含依赖退款、空白下一层、档口交换及保存回滚、键鼠和模拟手柄输入、改键冲突和松开提交、焦点/暂停恢复、教学、收集页、助手配送、菜单、AGI结局及连续12顿自动游玩。中英文实际窗口覆盖1280×720、960×540；助手分工另覆盖1920×1080。

目检了实际渲染的改键首屏及冲突说明、档口换位前后、英文空白便签、思考状态和助手分工。960×540改键首行完整可见；长英文反馈与底部按钮分开，档口说明正常换行；助手职责图形与分工按钮一致，状态图例和接力说明分行。保留原色板与原场景结构。

## 中途发现与保留的失败记录

1. `build/verification-20261019T160547Z/report.json` 为56/57通过。旧状态夹具买了所有下游节点却仍断言父节点可以全部退掉，与新规则冲突。修正为选择没有已购下游的节点检验完整退款往返。
2. `build/verification-20261019T162010Z/report.json` 为56/57通过。助手持续运行的语义检查完成，但退出时报告13个资源未释放。夹具现在等待真实结算协程结束、确认场景释放，并让渲染/音频资源正常退休；未过滤错误或放宽通过条件。
3. `build/verification-20261019T174318Z/` 保留超时日志与 `report-aborted.json`，不作为通过证据。默认窗口运行有场景超过120秒；旧英文退款夹具仍断言被替换的翻译键。同时目检发现改键窗口首次打开会滚动到第一行中间，这是实际UI缺陷。修复为等容器布局完成再启用焦点滚动，增加第一行可见区域检查，随后重新冻结源码、导出并运行整轮验证。
4. `build/verification-20261019T180310Z/` 保留设置窗口的三项顿帧恢复时间断言失败，以及两种语言助手窗口运行超过300秒的记录。相同顿帧断言在无窗口检查通过；旧等待函数在 `process_frame` 发出后、Fx本帧处理前就读取速度。定向复测修正测试取值时机，并在设置/助手夹具中明确关闭VSync，避免 `Settings.apply()` 再次开启。正式游戏的顿帧逻辑、渲染设置与助手行为不因此改动。

自动输入与实际渲染证明所列流程可运行、对应状态可显示；尚不等同于实物手柄兼容、真人手感或新构筑平衡验收。
