# 档口、菜和套餐（2026-10-16 定稿）

数据全在 `game/data/menu.json`：改菜、改速度、加套餐只改这个文件。

## 接饭
- 梁阿姨的每个窗口都属于一个档口，名牌上有出餐进度条和**下一道菜**的图标。
- 菜从本窗口的饭盆里轻轻往上一抛，然后**基本垂直落下**（「阿姨手不抖」= 落得更准）。
- 每样菜下落快慢不同（青菜飘、鸡腿快、荷叶饭最快），每次再随机 ±12%。
- 饭盒只能在**一条横带**里移动（柜台下方到地面上方），地面层留给外包小助手。
- 例外照旧：难题（V3.1 试炼）会斜着乱飞，「极」到处乱跳。

## 档口（技能树上方一支，每个档口一个节点，升级 = 菜单多一级）
| 档口 | 开局 | 出餐 | Lv1 | Lv2 | Lv3 | Lv4 |
|---|---|---|---|---|---|---|
| 主食 | 开局 Lv1 | 快 | 一碗饭（2 格）、馒头 | 饭团、白粥（2 格） | 炒饭 | 荷叶饭（稀有） |
| 炒菜 | 第一个解锁 | 中 | 炒青菜、番茄炒蛋 | 土豆丝、红烧肉 | 宫保鸡丁 | |
| 面点 | 早期 | 快 | 肉包、油条 | 豆浆、饺子 | 小笼包 | |
| 炸物 | 中期 | 慢 | 鸡腿、薯条 | 冰可乐 | 炸鸡汉堡（2 格） | |

窗口数（梁阿姨的触手）照旧单独升级，窗口轮流分给已开的档口。高峰期全体档口出餐 ×2.5，稀有菜更常见。

## 套餐 = 自动合成（没有通用套餐，只有具体的套餐）
- 饭盒里凑齐一个套餐的原料，**接住最后一样的瞬间自动合成**一份套餐：原料消失，变成一道占格更少的套餐，格子自动重排。
- 原料差一格放不下、但合成后放得下时，也接得住。
- 套餐也能当别的套餐的原料（连锁合成），比如「番茄炒蛋配青菜」+ 一碗饭 = 「家常便饭」。
- 价值 = 原料价值之和（青菜算 1）× 倍率：本档口 1.15，跨档口 1.3，隐藏 1.6（首轮 40 顿测试里 1.3/1.5/2.0 让中后期快了约 40%）。
- 大肥鱼吃一份套餐**只算一口**，所以凑套餐还让她吃得更快。
- 第一次合成某个套餐：「新菜谱！」，记进存档的菜谱图鉴（技能树里能看）。隐藏套餐在图鉴里只显示提示。
- 不做：套餐洒出、粥会洒、冰激凌会化（太复杂，先不加）。
