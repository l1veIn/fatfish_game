# 标题与辅助界面重做

标题使用真实生成的中英文透明字标。左侧为深海蓝品牌与操作区，右侧保留暖光中的完整角色；不再漂落食物或晃动排字。主动作暖金色，其他入口采用较薄的黄铜边奶油按钮，法律署名放入独立底栏。

设置使用奶油纸页面与深海蓝分类栏，音量、显示、辅助和游戏各有明确页题。所有长标签独立换行，选项保持原即时保存、焦点恢复和语言切换逻辑。暂停是独立休息牌：主恢复动作更亮，退出类动作更安静，子页面取消仍回暂停。

结账是宽账页：左侧收入明细与独立金额列，右侧深海蓝汇总区，已获得倍率逐条列出，没有空问号印章暗示不存在的解锁。合计与返回操作独立。支持原结算播放和跳过接口，减少动态时直接快速完成。

结局改为独立奶油叙事卡、细铜线、海蓝背景与角色暖光，保留三页叙事与继续玩法接口。

定向测试 `game/tests/presentation_shell_test.tscn` 需要 `--test-profile=presentation_shell_*`。覆盖标题真实字标、设置四页和键盘焦点、暂停内设置取消层级、结局翻页、密集结算与手柄确认。截图与源码哈希输出到 `--out` 指定目录；并非完整流程或实物手柄验证。最终视觉需在 1280×720、960×540 的中英文截图中逐页检查。

首轮实际 GPU 检查：英文与中文均为 1280×720（第二轮 CLI 指定 960×540，但被 Settings 恢复窗口尺寸，报告如实记录为 1280×720；不得计为小窗口验收）。目检后修复标题背景接缝、设置页英文孤行、结局尾句压角色、减少动态时结算按钮仍淡入的问题。定向测试已改为在 autoload 后显式设置并断言实际窗口尺寸；由根最终统一回归生成双语双尺寸证据。新字标装饰纠正版替换后也需要最后重拍。
