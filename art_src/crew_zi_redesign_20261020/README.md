# 双子造型重绘 · 2026-10-20

按用户提供的 `refs/ai_girl/gemini.jpg` 重绘，恢复粉金异瞳、紫色猫耳猫尾、紫粉渐变长发、四芒星饰物与星空服装。沿用游戏现有 Q 版角色比例，替换接餐、跑动、庆祝、休息四个状态。

- `identity.png`：本轮角色设计母版。
- `stand.png`、`run.png`、`cheer.png`、`sleep.png`：透明原图，与 `game/assets/crew/zi*.png` 中对应文件逐字节一致。
- `preview.png`：Godot 实际渲染的浅色、深色背景四态预览。
- `manifest.json`：内置生图工具、完整提示词、参考来源、文件哈希与验收记录。

Godot 导入限制接餐、跑动、庆祝贴图为 512 px，休息贴图为 448 px，以保持坐姿头部大小相近；四态均启用 mipmap，改善实际游戏尺寸下的缩小采样。没有修改助手玩法、碰撞范围、速度或存档标识。`pipeline/prep_rig.py` 从此目录复制完整原图，避免以后重新生成时恢复旧造型。

验收包括四态实机截图、自动化面板与助手整班回归，以及导出的 Windows 程序运行检查。专用四态截图使用指定位置和姿态的视觉夹具，不代表真人游玩评价。验证和打包运行均使用隔离测试档案，玩家存档、备份和设置的前后哈希一致。
