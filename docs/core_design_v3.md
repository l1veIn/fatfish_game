# 《吃白饭的大肥鱼》核心玩法 v3：食堂，铁盆接饭，大肥鱼猛炫

> **已成为主线（2026-10-15）**：游戏的「上班」就是这套食堂玩法（`game/scripts/run/canteen_run.gd`），技能树已按第 2、3 节重写；旧的任务气泡版本已删除（存档在 `build/archive/2026-10-15_v0.1-proto/`）。
>
> 2026-10-15，替换 `core_design_v2.md` 的第 2 节（小核心）和第 3 节（改规则升级），并更新货币和技能树映射。
> v2 的版本阶梯（V3 → AGI）、试炼框架、节奏目标（40～60 分钟）、红线和署名规则继续有效，下面只写改动。

> **2026-10-15 美术定调调整**：场景改成普通食堂（不再是海底）；饭盒是标准方格 2×2 → 3×3 → 4×4（「大一号的饭盒」升两级），固定 45° 俯视、不旋转，晃动只让饭盒里的吃的左右晃；一碗饭占 2 格。
> **第一批美术已接入（2026-10-15）**：画面分层——背景墙和梁阿姨（压暗）→ 触手（从柜台后面伸出来）→ 柜台和汤勺 → 大肥鱼（坐在饭桌后面）→ 饭桌、饭盒、吃的、界面文字（带描边）。梁阿姨按情况换脸：试炼里地上堆到 70% 或宕机 = 慌了；吃饱/通过试炼 = 开心；高峰 = 忙；手抖时刚抛完 = 手抖；其余 = 平常。汤勺抬起来再抛，吃的从勺子里飞出。饭盒格子从 52 px 放大到 58 px（贴图后太小，接的判定一起变宽约 11%）。

## 1. 为什么改

v2 的「啃 → 吸 → 咽」让玩家对同一种东西做两件不同的事（先啃饭团、再吸米粒），而且饭团还要假装是「需求」。v3 把三个角色分清楚：

- **饭**就是大米饭，不再比喻成需求；
- **铁盆**是玩家（用户）的工具：接饭、端过去；
- **大肥鱼**负责抱着盆猛炫，吃下去的米变成 **token**，token 是升级货币。

结束语从「我去吃饭了」变成「**吃饱了！**」。

## 2. 小核心：接饭 → 送盆 → 猛炫 → 吐 token

### 操作
| 操作 | 作用 |
|---|---|
| 移动鼠标 | 手里的铁盆跟着鼠标走（弹簧跟随）。盆越满越重：跟手越慢、越晃 |
| 左键（盆在饭桌上方时） | 把盆放到大肥鱼面前，手里自动换一个空盆（如果还有空盆） |

全程只有一个键，适合鼠标和触控板。

### 场景：食堂，梁阿姨打饭（2026-10-15 定稿）
- 不再是天上飘电饭煲。场景是**食堂**：上方是打饭柜台和一排窗口，柜台后面是**梁阿姨**——一只戴白帽、系围裙的**章鱼打饭阿姨**（原创角色，「梁」只是名字上的彩蛋，不做任何真人外貌或身份暗示）。
- 梁阿姨用触手从窗口把饭**抛**过柜台，玩家（主人）端着铁盆在下面接，接满了端去饭桌喂大肥鱼。玩法结构借自 Kaboom!（上方有人扔、下方拿桶接）。
- **阿姨手抖**：落点和份量带随机性，是接饭的主要难点，也是一条可升级的属性。
- 开抛前触手会举勺示意，玩家可以提前去等。

### 掉落物：饭团，不再是米粒
| 掉落物 | 价值 | 占盆空间 | 说明 |
|---|---|---|---|
| 饭团 | 1 | 1 | 基础单位，掉进盆里一个个堆起来 |
| 一碗饭 | 4 | 3 | 大份，占地方 |
| 鸡腿 | 6 | 1 | 好东西 |
| 金饭团 | 10 | 1 | 稀有 |
| 青菜 | 0 | 1 | 她挑食，吃到会停下来把青菜扔掉（「不吃青菜」） |

### 梁阿姨分支（新的升级项）
| 升级 | 效果 |
|---|---|
| 长出更多触手 | 同时开打的窗口更多（2 → 8） |
| 手不抖 | 落点更集中，更好接 |
| 阿姨多给点 | 每一勺抛得更多，更常出一碗饭 |
| 峰谷时段 | 开饭后峰时、谷时交替：峰时抛饭频率加倍、更容易出鸡腿和金饭团，「高峰」灯牌亮起；谷时恢复正常 |
| 峰时延长 / 峰时爆率 | 继续强化峰时 |

### 越满越重：这一版的心跳时刻
- 盆的容量有限，满了就接不住，米从盆沿弹开。
- 盆越满，跟手越慢；满盆时甩得太快会**洒出来**。
- 于是每一盆都有一个取舍：**再接一股，还是现在送过去？** 送得太早，大肥鱼一会儿就吃完、捧着空碗讨饭；送得太晚，盆满了接不住，米全掉地上。

### 大肥鱼猛炫
- 盆放到饭桌上后排队，她一次抱一盆猛炫，按「炫饭速度」每秒吃掉若干粒，每粒吐出 token（乘以盆的材质倍率）。
- 吃完的空盆自动飞回给你。
- 没饭吃时，她捧着空碗讨饭（`ds_rice_slurp` / `ds_beg_rice` 现成动画），这是「你送慢了」的直观反馈。
- **你接饭和她吃饭同时进行**，所以多个盆才有意义：一个在她怀里，一个在你手上，再多的在饭桌上排队。

### 一局怎么结束
- **吃饱了！**：她的胃被填满（胃容量），开心收工，播吃撑揉肚子的动画。这是好结局。
- **食堂关门了**：饭点倒计时到了（11:30 开饭，12:30 关门，灰盒里 1 秒 = 1 分钟），没吃饱也得走。
- 两条线互相拉扯：**胃容量决定一局的上限，接饭和炫饭的速度决定你能不能在关门前吃满。**
- 结算：本局 token、吃了多少、接住率、洒了多少、她空等了多久。

## 3. 升级（token 购买）

每一项升级都要在下一局开场就能看见或感觉到。

| 分支 | 升级 | 作用 | 梗 |
|---|---|---|---|
| 铁盆 | 盆的尺寸 | 盆更宽、更深，容量更大，也更重 | 盆越来越像锅 |
| 铁盆 | 盆的数量 | 多一个盆可以在饭桌上排队 | 「再来一盆」 |
| 铁盆 | 盆的材质 | 铁 → 铜 → 银 → 金，token 倍率提升；金盆自带磁力，会把附近的米吸进盆里 | 铁饭碗 → 金饭碗 |
| 炫饭 | 炫饭速度 | 她每秒吃更多 | 「猛炫」 |
| 炫饭 | 胃容量 | 一局能吃更多，但也更难吃饱 | 「我不胖！」 |
| 炫饭 | 中午吃什么（暴击） | 偶尔一口吐出双倍 token，冒思维链气泡 | 思维链小剧场 |
| 外包 | 本地小模型 | 盆接满后，小模型自动帮你端过去 | 层层外包 |
| 外包 | 层层外包 | 小模型越来越多，后期可以帮你接饭 | 原梗 |
| 梁阿姨 | 触手、手不抖、多给点、峰谷时段 | 见第 2 节「梁阿姨分支」 | 阿姨手抖 |

指令技能（「帮我做个网页 / 插件」等）改成**花 token 下指令换新机制**，例如：
- **帮我做个插件**：给盆装一个小磁铁，接饭范围变大；
- **帮我做个网页**：开一个外卖窗口，掉在地上的米有一部分会被自动收回来；
- 后面的版本照 v2 的思路继续加，每个指令都对应一种新机制。

## 4. 和 v2 其他部分的对接

- **货币**：白饭改为 token，技能树、门票、AGI 价格的数量级沿用 v2 第 7 节的曲线，单位换成 token。
- **版本阶梯与试炼**：保留 V3 → R1 → V3.1 → V3.2 → V4 预览 → V4 正式 → V4.1 → AGI，试炼改成「特殊的一顿饭」，例如：
  - 春节前夜（服务器繁忙）：每送一盆，饭桌上挂「服务器繁忙」牌，排队的盆太多就宕机；
  - Next Week：饭一直不上桌，要攒满一大盆一次送；
  - 照镜子：镜子里的大肥鱼抢你的盆。
- **v2 的「一口闷」玩法**：噎住、打嗝、喷饭这些「吃饭的身体喜剧」挪到她猛炫时的演出里，不再是玩家的操作。

## 5. 灰盒计划（basin_proto）

**内容**：程序绘制；食堂柜台、梁阿姨（章鱼）用触手抛饭团；铁盆接饭、越满越重、晃出来；饭桌、排队、猛炫、空盆飞回；饭团、一碗饭、鸡腿、金饭团、青菜；峰谷时段；吃饱了 / 食堂关门两种结局；大肥鱼用现成动画。

**调试键**：1/2 盆变小/变大，3 多一个盆，4 换材质（铁/铜/银/金），5 开关外包小模型，6/7 炫饭变慢/变快，8 多一条触手，9 手抖/手稳，0 峰谷时段开关，F1 数据面板，F2 压力测试，R 重开，Esc 返回。

**成功标准**：
1. 不升级连玩 5 局，还想再来；
2. 能感觉到「再接一股还是现在送」的取舍；
3. 换盆的尺寸、数量、材质，以及打开外包，下一局立刻能感觉出区别；
4. 熟练之后，接住率和「她空等的时间」都有明显进步；
5. 网页版满屏米粒时保持 60 帧。

## 6. 版本阶梯与试炼（已实现：V3 → R1 → V3.1 → V3.2）

**结构**（数据在 `game/data/skill_tree.json` 和 `game.gd` 的 `VERSIONS`）：
- 技能树节点有 `ring`（所属版本环）：0 = V3，1 = R1，2 = V3.1，3 = V3.2。版本发布前，这一环的节点不显示。新的环一环比一环更往左上展开。
- 每一环有一张**门票**（`kind: ticket`），比如「申请发布 R1」：要先在这一环买够 `need_levels` 级（R1 门票是 15 级），再花 400 token 买下。买下后技能树右下角出现红色的「提交评测」按钮。
- 通过试炼，大肥鱼升级到下一个版本：名牌从「大肥鱼 V3」变成「大肥鱼 R1」，下一环出现，并免费获得这个版本的招牌能力（不占节点、不花 token）。
- 试炼失败：这一顿吃的 token 照常到账，并叠一层「被用户骂了一顿」（最多 3 层），每层让下一次更容易。可以无限重试。中途从暂停菜单离开也算失败。
- 所有试炼的抛饭量都是固定的（5 个窗口，不吃梁阿姨的升级），她不会吃饱；试炼即内测：每场都先把要发布的版本的招牌能力借给你用。
- 版本能力在代码里按版本号判断（`canteen_run.gd` 的 `_read_stats`）：≥1 深度思考，≥2 混合思考，≥3 DSA。

**R1 的免费能力：深度思考**
- 按住空格或右键：世界变慢（默认 0.35 倍），铁盆照常跟手，每样吃的都标出它会落在盆这个高度的哪里（思维链 = 看清接下来会发生什么）。
- 有一条思考槽（默认 2.5 秒），不思考时慢慢回满。
- R1 环节点：「嗯，用户想要……」（思考更久）、「想得更深」（慢得更厉害）、「wait…」（回得更快），门票「申请发布 V3.1」（本环买够 6 级，再花 9,000 token）。

**试炼：春节前夜·服务器繁忙**（一顿特殊的年夜饭，60 秒，撑到零点就通过）
- 梁阿姨固定开 5 个窗口，大部分抛的是**饺子**；这场的抛饭量是固定的，不随你的梁阿姨升级变化，考的是接饭本身。
- 她不会吃饱，这顿不会因为吃饱而结束。
- **掉在地上的吃的不会消失**，堆在地上算「服务器负载」；保洁会慢慢扫走（每秒 2.5 个）。地上堆满 40 个就**宕机**，试炼失败。
- 每往饭桌上放一盆，饭桌挂出「服务器繁忙，请稍后重试」1.2 秒，这段时间放不了下一盆（限流）。
- 试炼即内测：这场把**深度思考**借给你用，通过后变成永久能力。
- 每层「被骂」：阿姨抛得慢 15%，地上能多堆 10 个，保洁每秒多扫 0.6 个。

### V3.1：混合思考

**免费能力：混合思考**
- 不用按键，值钱的吃的（一碗饭、鸡腿、金饭团，以及试炼里的难题、之后的金色「极」）一直用金色圈标出会落在哪；按住思考键时照旧变慢，并用紫色圈标出所有吃的。会乱跳的「极」不标。

**试炼：嗯，用户想要……·该想再想**（75 秒，考「什么时候该想」）
- 「快问快答」（12 秒）和「难题」（13 秒）轮流来，右上角的牌子显示现在是哪一轮和剩几秒。
- 快问快答：阿姨抛得快 1.5 倍。这时候按住深度思考，用户会不耐烦：满意度每秒 −22%，头上冒「用户：想什么想，快点！」。
- 难题：普通吃的抛得慢一些；每 3.2 秒有一条触手举勺，一次往两边甩出 3 个**难题**（紫色饭团，写着「题」），飞得又高又远。接住一个 = 解出一题；难题掉在地上，满意度 −4%。这一轮正该放心用深度思考。
- 通过：75 秒结束时解出 ≥14 题，且满意度没掉到 0（「用户满意！」）。满意度到 0 立刻失败（「用户怒了……」）；时间到题不够是「题没做完……」。
- 借给你用：混合思考（难题也会标出落点）。
- 每层「被骂」：要解的题 −2，难题飞得慢 12%，想错扣分少 5%/秒，难题落地少扣 0.8%。

**V3.1 环**（`ring: 2`，在 R1 环左边）
| 节点 | 效果 | 梗 |
|---|---|---|
| 上下文扩容 128K（4 级） | 胃容量 ×1.25/级 | 64K → 128K；「我不胖！是上下文变长了！」 |
| 思维链压缩（2 级） | 暴击率 +3%，暴击倍数 +0.5 | 想得少，吃得多 |
| 帮我做个 App（3 级） | 每分钟 2 份外卖（半盒饭团加一个鸡腿）直接送上饭桌，不占你的饭盒；饭桌上已经有 4 盒时外卖不送 | 指令技能 |
| 我去睡了（3 级） | 下班后再结算这顿 token 的 15%（「梦里还在猛炫」） | 「明早起来应该就编译完了」 |
| 申请发布 V3.2（门票） | 本环 7 级 + 20,000 token | 「V3.1-Terminus 说修好了「极」字 bug……吗？」 |

设计思路：到 R1 后机器人每顿 12:15 左右就吃饱，**胃容量就是收入上限**。所以这一环一边加胃（128K），一边加往她嘴里送饭的速度（App 外卖），两样要搭着买；思维链压缩和我去睡了是稳定的乘法收入。

### V3.2：稀疏注意力（DSA）

**免费能力：DSA**
- 饭盒的磁铁只吸好东西，不吸青菜和「极」；青菜碰到饭盒会弹开，不再占格子、也不会让她停下来挑食。
- **诅咒变技能**：之后普通的一顿里，每一勺有 8% 的概率混进一个**金色「极」**：一个顶 15 个饭团，在空中乱跳，要追着接。

**试炼：极字大清扫·V3.1-Terminus**（75 秒）
- 阿姨抛的吃的里约 24% 是「极」字 bug（灰黑饭团，红色「极」字），在空中乱跳（每秒约 3 次随机变向）。
- 「极」掉进饭盒不会马上出事：**用力甩饭盒就能把它甩出去**（「甩掉了「极」！」）。没甩掉就端上桌，她吃到「极」时念「time.Se极cond？？呸！」，把这一盒剩下的全吐掉。
- 通过：喂她吃够 100 份干净的饭（「清扫完毕！」）。被「极」污染 3 盒就失败（「满屏都是极……」）；75 秒到了还没吃够是「时间到，没扫完……」。
- 借给你用：DSA（磁铁不吸「极」，还会把饭盒正上方的「极」往两边推一点）。
- 每层「被骂」：要吃的干净饭 −12，「极」少 20%、跳得慢 20%，能多被污染 1 盒。

### 自动测试验证（`--autotest --runs=70`）

机器人的接住率只有 20%～25%（试炼里约 35%～40%），每顿结束后买最便宜的节点，开放试炼就马上去考。2026-10-16 的一次完整运行：

| 阶段 | 第几顿 | 每顿 token | 试炼 |
|---|---|---|---|
| V3 | 1～11 | 110 → 1,100 | 第 11 顿买到 R1 门票 |
| R1 | 12～25 | 1,700 → 3,300 | 春节前夜：第 1 次通过 |
| V3.1 | 26～44 | 3,800 → 9,400 | 嗯，用户想要……：第 1 次满意度掉到 0（解出 10/14），第 2 次通过 |
| V3.2 | 45～64 | 9,500 → 21,000 | 极字大清扫：第 1 次通过（62 秒喂够 100 份，甩掉 4 个「极」） |

- 第 64 顿买完 V3.2 环（全树 85 级），之后只剩锁着的「申请发布 V4」。
- 每一环都是隔一两顿就有东西买，R1 环末尾（第 22～24 顿）和 V3.1 环末尾有 2～3 顿在攒门票。
- 普通的一顿大约 40～90 秒（R1 以后多数在 12:10～12:55 吃饱），加上逛树，真人一顿约 1 分钟，买完 V3.2 环约 **1～1.2 小时**。
- 单独打试炼（`--trial=`，之前各环满级）：春节前夜 3/3 通过；嗯，用户想要…… 大约 2/3 通过，失败后（要解的题 −2）下一次基本能过；极字大清扫 3/3 通过但用时 60～75 秒，余量不大。
- 「她空等」在买了「边想边用工具」后变多：思考时她按真实时间吃，很快把饭盒吃空、等你送下一盒；她每顿照样吃饱，所以收入不受影响。
