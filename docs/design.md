# 《吃白饭的大肥鱼》设计草案

## 定位
- 粉丝向的短篇增量游戏，结构参考 Nodebuster 一类：3～5 小时通关，"上班一局 → 技能树 → 再上班"，基本没有挂机
- 结构故意做得和同类游戏一样，梗都放在角色、技能树、美术和音效里
- **免费发布**（itch.io / B 站 / 免费 Steam 页）。角色素材依 CC BY-NC-SA 4.0 二创，不能卖、不能内购

## 核心循环
| 结构 | 大肥鱼版本 |
|---|---|
| 一局 | 一次"上班"：需求、bug、加急任务漂过来，鼠标就是大肥鱼的嘴，范围内的任务每 0.2 秒被吃一口 |
| 结束 | 饱腹值（秒）耗尽 →"我去吃饭了！" |
| 货币 | 白饭（token） |
| 转生（待做） | "上下文满了，开启新对话"：重置技能树，保留"记忆" |
| 结局（待做） | "oi！蓝色大肥鱼，你实现 AGI 了吗？"→ 实现 AGI 后第一件事是去吃白饭 |

## 技能树分支（数据在 `game/data/skill_tree.json`）
- **吃饭系**：碗更大（饱腹值）、饭量
- **外包系**：本地小模型 → 层层外包（自动吃任务的帮手）
- **思维链系**：中午吃什么（暴击）→ 卧槽，我不思考了（低饱腹值时狂暴）
- **摸鱼系**（待做）：猜词小游戏、卖汉堡、钓鱼作为奖励小游戏
- 跃迁节点："这次只写了一部分"（残血任务直接完成）、"我去睡了，明早应该就编译完了"（后期离线收益，吐槽挂机游戏）

## 让进度看得见
- 大肥鱼随技能总等级越吃越胖（目前是程序画的占位形象，`fat = 1 + 0.04 × 总等级`）
- 待做：技能树点满时拼出饭碗或鲸鱼剪影
