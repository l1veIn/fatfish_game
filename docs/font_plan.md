# 字体：要不要自己设计（2026-10-18）

## 结论

**不做完整的中文字体。** 只做两样：
1. 「饭票数字」：一套二十来个字形的数字字体；
2. 标题字图：「吃白饭的大肥鱼」的 logo。

正文和小字继续用现有的两款开源字体。

## 为什么不做完整字体

- **字数太多**：游戏现在用到的中文字就有一千多个，以后加内容、加图鉴只会更多，常用字表是 3500 个。自己画，字和字之间的粗细、重心、间距很难做统一。做不精的自制字体，比现成的好字体更显廉价。
- **AI 生图做不了**：生图模型画汉字经常缺笔画、错字，不能当字体来源。
- **现成的已经合适**：两款字体都是 SIL OFL 授权，Steam 上用没有问题。
  - 思源黑体（Noto Sans SC）：正文清楚，小字号好读；
  - 站酷快乐体：圆、胖、有食堂手写牌的味道，标题够用。

## 1. 饭票数字（建议做，优先级高）

增量游戏的爽感一大半在数字上：金额滚动、倍率盖章、「×1.23」一个个往上翻。现在这些数字用的是站酷快乐体，能用，但没有记忆点。

**范围**：
- 0–9、`×`、`+`、`−`、`%`、`.`、`,`、`/`；
- `万`、`亿`、`K`、`M`（英文版用）；
- 外加 token 小图标。

一共大约 25 个字形。

**样子**：
- 像饭票上用印章打出来的号码：粗、圆头、略微不规则的油墨边；
- 三套颜色：金（钱）、红（盖章和暴击）、蓝（搪瓷倍率）；
- 描边和投影直接烘进图里。

**做法**：不用生图模型画数字。用站酷快乐体的数字当骨架，在 Python 里做效果：加粗、圆头、油墨边、内阴影、描边，导出成一张字形图集，在 Godot 里做成位图字体（`FontFile`，或 BMFont 格式）。
- 免费，可以反复调；
- 风格自动和标题字统一；
- 字数少，每个字可以单独微调。

**用在**：
- 收银台的大数字；
- 飘字（+12、×2 暴击）；
- 搪瓷徽章；
- 结账小票的金额和盖章；
- 技能树价格。

## 2. 标题字图（建议做，上架前必须有）

商店页的胶囊图、游戏标题画面都需要一个专门设计的 logo，而不是一行字。

**样子**：
- 「吃白饭的大肥鱼」七个字，用站酷快乐体当骨架，手动调大小错落：「白饭」做成一碗饭的造型，「鱼」字带一条鲸鱼尾巴；
- 外面一圈米白描边加深棕投影，和饭票纸的配色一致；
- 另做英文版「Fatfish's Free Lunch」。

**做法**：
- 字用现成字体排版、在代码里加效果，保证每一笔都对；
- 装饰元素（饭粒、热气、尾巴）可以用生图做成单独的透明小图，再拼上去。
- 生图前照例先报数量和费用，预计 3–5 张，约 0.2 美元。

## 3. 不变的

- 正文：思源黑体。
- 标题、按钮、横幅：站酷快乐体。
- 中文文本变了以后照旧重跑 `pipeline/subset_font.py`。
