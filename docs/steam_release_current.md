## Steamworks 尚待配置

尚未提供 App ID、后台权限或平台 SDK。游戏内成就是本地持久化，不是 Steam 平台成就；不能在商店勾选已实现平台成就。后续接入时，将稳定 ID 映射到 Steamworks 定义，登录后回填已获得项目并验证断网重连。

商店页面与游戏构建有各自的检查和审核步骤，只有后台实际通过才标记完成；发布操作由作者在审核通过后执行。具体等待时间与账号要求以当前 [Steam 发布流程](https://partner.steamgames.com/doc/store/releasing) 为准。

### 云存档准备值

可使用 Steam Auto-Cloud，不必为了云同步先添加运行时 SDK。需在后台实际保存、发布，并用第二台机器验证往返同步；官方说明见 [Steam Cloud](https://partner.steamgames.com/doc/features/cloud)。

| 项目 | 准备值 |
| --- | --- |
| Root | WinAppDataRoaming |
| Subdirectory | FatFishFreeLunch |
| Pattern | 单独两条：`save.json`、`save.json.bak` |
| Recursive | 不递归 |
| OS Restriction | Cross-Platform；其他平台推出时再配对应 Root Override |

不要同步 `settings.cfg`（含机器窗口设置）、`qa_*`、`autotest_*`、`.tmp` 或整个目录。原文档的 `save.json*` 会把未完成的临时写入也带进云端，因此不沿用。当前共用本机档案，尚未按 Steam 用户 ID 隔离，多账号共机和云冲突仍须实测。

## 从候选版到精品的后续验收

1. 至少三名首次接触游戏的玩家，记录第一盒送达时间、卡住位置、每次评测尝试与版本升级耗时。
2. 暴食、套餐、美食评鉴、吃菜顿悟四种构筑各完成一轮；不要只用“买最便宜”的机器人证明平衡。
3. 实物手柄和 Steam Deck 全流程、小屏字体、不同桌面分辨率、焦点丢失与暂停恢复。
4. 低配硬件长时间运行、最高食物/助手负载、实际音频听审。
5. 独立发行包启动、冷启动/异常退出/重新打开、云存档双机和 Steam 成就联调。

这些关卡没有通过前，可以交付可玩的候选版，但不能宣称已经达到精品品质或完成上架。
