# 原版视觉的局部精修 · 2026-10-19

目标：消除临时 HUD、无标识档口、视觉隐喻错误、贴纸素材滥用、小图细节丢失、标题字体占位、文字遮挡及溢出。每一区域有自己的材质与尺度，而不是全屏放大一种边框。

## 设计边界（按玩家纠正更新）

以 `30e97c7` 的原暖色手绘食堂、奶油纸、木边按钮、小黑板和搪瓷乘区徽章为基准。用户要求提高具体细节的完成度，没有要求改变整体配色和布局。最初实施的深色一体账板、冷色统一主题与固定技能详情侧栏已撤回。每处改动必须对应一个可指出的原缺陷，并对照原界面验收。1920×1080 逻辑画布，1280×720 与 960×540 双语检查，不以统一重做替代细节修整。

- 局内：原左上计时小黑板、右上收入饭票/营养盘与逐枚乘区徽章不变。深度思考用同一小黑板材质配原有手绘时钟，放在不挡阿姨的位置。原柜台上补搪瓷档口牌与独立勺子预告，详细解释点击查看。
- 标题：生成真正的中英文手绘游戏字标，大尺寸设计，独立于角色与按钮。标题、暂停、设置、结算统一精致材质与明确层级，不用放大的技能贴纸充当窗口。
- 图鉴：真正分页的双页料理书，目录/分类、翻页和页码；书页区域不放滚动网页。食材和规则也走同一翻页语义。
- 成就：独立的奖章/收藏陈列设计；小尺寸专用图标以一个大形状表达主题。原复杂半身立绘可在详情处展示，不能缩成不可辨的小卡图。支持分类/分页与明确详情。
- 技能树/菜单：保留软木板、红线、贴纸、原地图结构与浮动黑板说明。只修贴纸相交、等级被边框遮挡、非满级盖章和长文越界；菜单保留原三列图片卡片与暖色，修正巨型拉伸贴纸边框。

## 分工与接口

根负责 `canteen_run.gd`、新局内呈现模块、公共 `UiKit`、全部新生图和资产、翻译/字体合并、最终验证和 Git 提交推送。

标题分工拥有 `title_screen.gd`, `ending_screen.gd`, `settings_panel.gd`, `pause_menu.gd`, `checkout_receipt.gd` 及对应新的定向测试。图鉴成就分工拥有 `recipe_book.gd`, `achievements_panel.gd`, `achievement_toast.gd` 及新的收藏界面测试。技能树分工拥有 `tree_screen.gd`, `meal_planner.gd`, `run_coach.gd` 及其定向测试。不并行改公共状态或翻译文件。

图片统一放 `game/assets/ui/premium/`。标题 `logo_zh.png`, `logo_en.png`；小尺寸奖章 `badge_meal.png`, `badge_growth.png`, `badge_recipe.png`, `badge_balance.png`, `badge_kitchen.png`, `badge_gold.png`；书页 `recipe_spread.png`。未到位时允许开发期间暂用旧图，不得以临时图作为最终交付。

## 验收与提交

所有新入口、翻页、键鼠/模拟手柄、暂停内子界面返回需走实际 GUI 事件。真实 GPU 截图核查中英文、最密集/最长文本、锁定/未解锁/满级、不同窗口尺寸。玩家存档隔离。每块完成并检查后由根单独 commit；最后更新候选包和验证记录，推送当前分支，不覆盖远端历史。自动检查数量不能代替画面检查或宣称玩家无可挑剔。
