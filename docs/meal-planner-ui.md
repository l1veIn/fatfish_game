# 开饭前菜单夹

`TreeScreen` 只持有一个 `MealPlanner`。今日菜单与招牌菜在同一层模态内切页，重复打开不会叠加；选择后原卡片原位更新，避免旧实现关闭后又新建导致的焦点丢失和多层窗口。

画面沿用奶油饭票、木边和暖金色。1920×1080 逻辑画布缩放到 1280×720；左侧三列菜品卡使用现有各菜独立 PNG，右侧预留 470×326 的透明鱼插画、当前名额、选择摘要与当前菜的解释。未解锁、当前招牌、被划掉各有文字状态，划掉另加红斜线和降饱和，不能仅靠颜色识别。

- 插画：`game/assets/portraits/release/fish_menu_curator.png` 和 `fish_signature_chef.png`。资源未就绪时使用现有 FishRig；角色仍按 Game.emotion() 控制表情。
- 操作：鼠标点击，方向键/摇杆导航，Enter/A 选择，Tab 在模态内循环，Esc/B/返回/准备好了关闭并恢复原工具栏焦点。
- 模态打开时，底层工具栏不参与焦点，技能树的拖动、缩放、购买、退款、开饭快捷键均不接收输入。打开时移走新功能提示卡。
- 选择由 Game 接口即时保存，UI 不另存一份。招牌依 Game.active_signatures() 自动补足，满额新选替换最早一项；页面明确解释这条规则。
- 菜单使用 Game.active_struck() 与 Game.struck_toggle_reason()：每个已开档口至少保留一道；最后一道的卡片标明必须保留，点击显示实际拒绝原因。锁定招牌显示对应档口的解锁等级。
- 技能贴纸：两行名称在上方正文区，下方安全内边距显示等级及细进度条；仅满级才在右下票根盖小章，部分购买不盖章。
- 顶部工具栏按实际内容宽度右对齐，英文不会把“标题”挤出屏幕。技能说明完整换行，并避开开饭与评测按钮的实际矩形。

`game/tests/meal_planner_test.tscn` 使用独立 `--test-profile=meal_planner_*`；覆盖反复打开、两个入口复用一个实例、鼠标/键盘/手柄选择、保留焦点、模态阻断、满额替换、未解锁菜与关闭恢复。截图测试是后期状态夹具，不代表从零完整游玩或实物手柄验收。
