# 核心设计 v4（2026-10-16，取代 v3 的结算、试炼和技能树部分）

档口、菜和套餐见 `docs/menu_design.md`，大肥鱼和小助手的动作见 `docs/fish_actions_design.md`。

## 1. 一顿饭
- 只有「食堂关门」一种结束。**没有吃饱上限**：大肥鱼一直吃，肚子越来越圆。
- 一顿的产出靠饭点长度、出餐速度、炫饭速度、饭盒、小助手，都可以无限往上升。
- 吃的时候实时拿**基础 token**；关门后结算乘倍率（像 Balatro 的计分）。

## 2. 结算倍率和流派
- **均衡倍率（均衡流）**：这一顿吃下的主食 : 荤 : 素（套餐按原料算）离「大肥鱼膳食宝塔」4 : 3 : 3 越近越高，×1.0（严重偏食）～ ×2.0（完美）。HUD 右上角的饼图实时显示比例和目标。
- **越吃越香（暴食流，技能「流式输出」）**：一顿里每吃 N 口，之后每一口价值递增。
- **招牌菜（某道菜的流派）**：开饭前选 2 道招牌菜（技能「MoE 激活专家」+1 位）。每个档口 2 道可选，选中后这道菜单吃或在套餐里都生效：

| 档口 | 招牌菜 | 效果 |
|---|---|---|
| 主食 | 饭团 | 每吃一个，本顿饭团价值 +2%（叠加） |
| 主食 | 白粥 | 每吃一碗，均衡倍率 +0.04（养生流） |
| 炒菜 | 土豆丝 | 每吃一份，本顿土豆丝价值 +4%（叠加） |
| 炒菜 | 红烧肉 | 价值 ×2.5，炒菜档口出餐慢 30% |
| 面点 | 饺子 | 每吃一个，本顿饺子价值 +3%（叠加） |
| 面点 | 豆浆 | 每杯均衡倍率 +0.04 |
| 炸物 | 炸鸡汉堡 | 价值 ×3，炸物档口出餐慢 30% |
| 炸物 | 薯条 | 每吃一份，本顿薯条价值 +4%（叠加） |
| 甜品 | 冰激凌 | 价值 ×2.5，甜品档口出餐慢 30% |
| 甜品 | 奶茶 | 每杯均衡倍率 +0.04 |

## 3. 试炼 = 一顿的 token 目标
- 发布评测就是一顿普通的饭，用你自己的全部构筑，结算后 token 达到目标就通过。
- 每次开始评测**交门票 = 目标的 10%**；失败只是门票没了，随时可以再试。
- 目标：R1 一顿 2000，V3.1 一顿 2 万，V3.2 一顿 6 万（V4 以后再定）。去掉吃饱上限后一顿能赚的大约是以前的 5 倍，技能价格暂时 V3 环 ×3、之后的环 ×5，技能树重做时再细调。
- 原来的三个特殊试炼规则全部删掉，名字保留为评测的梗标题。版本奖励（深度思考、混合思考、DSA）保留。

## 4. 技能树
- 主题：食堂后厨软木公告板，节点是饭票，红毛线相连，买满盖红章「已兑」；中心是大肥鱼，放射 6 支：档口、饭盒、大肥鱼、梁阿姨、外包、版本。右侧固定详情卡（前后数值对比、档口解锁的菜和能凑的套餐、兑换按钮），长按连买，购买有飞币、盖章、毛线亮起、新票弹出的反馈。
- 技能名多用 AI 梗，每个节点有前缀（Skill / Agent / MCP …）和一句人话说明。草案：

| 概念 | 技能 | 效果 |
|---|---|---|
| Skill | 自动推送 | 手里空着、桌上有空饭盒时，大肥鱼给你丢一个过来 |
| Skill | 自动回收 | 饭盒装满就自己飞回满饭盒区 |
| Agent | 招募小助手 | 外包小助手 |
| 多智能体协作 | 多 Agent 编排 | 小助手自动分区，不扎堆 |
| Function Calling | 点单 | 指定小助手只接某道菜 |
| MCP / 插件 | 帮我做个插件 | 饭盒吸附 |
| 上下文窗口 | 128K 上下文 | 饭盒加宽 |
| 长上下文 | 食堂晚点关门 | 饭点延长 |
| 上下文压缩 | 上下文压缩 | 套餐再省 1 格 |
| KV Cache | 缓存命中 | 连续接同一道菜价值叠加 |
| MoE | 激活专家 | 招牌菜位 +1 |
| 流式输出 | 流式输出 | 越吃越香 |
| RLHF | 人类偏好对齐 | 均衡倍率上限 +0.2 |
| Temperature | 温度调低 / 调高 | 二选一：落点更准 / 更散但稀有菜更多 |
| 幻觉 | 幻觉 | 偶尔饭盒里凭空多一份菜 |
| 量化 | INT8 量化 | 菜占格减半，价值 -20% |
| 多模态 | 多模态 | 开甜品饮品窗口 |

- **随时洗点**：两顿之间「回滚到 checkpoint」，所有技能节点全额退款；3 个构筑存档位一键切换。门票和版本发布不能洗。

## 5. 实施顺序
1. 规则：去掉吃饱和特殊试炼；均衡倍率、越吃越香、招牌菜、计分式结算卡、门票试炼；自动推送 / 自动回收；洗点（先用简单按钮）。
2. 档口：柜台 5 个固定档口（主食在中间），每级一张图，卷帘门，手写塑料牌，进度条和落点严格对齐，没开的档口不出菜；触手跟着档口走，「长出触手」改为「双勺」。
3. 技能树：饭票软木板 UI 和节点全部重排（先出一张效果图确认）。
