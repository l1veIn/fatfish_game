# 0.3 制作规格 · 从 demo 到完整体验

本轮目标：玩家第一次开饭能学会接菜送饭，达到 AGI 后得到明确收尾与可重看的结局，长期进度与成就可以可靠保存；设置和发布包具备继续验收的基础。目标平台是 PC / Steam 单机，沿用免费非商用粉丝作品定位、现有人设和 1920×1080 逻辑画布。

## 固定条件

- 保留现有五档口、74 节点与 V3 → AGI 的经济模型，不凭一次机器人回测重做平衡。
- 沿用奶油纸、木边、饭票、暖金色视觉，避免另造画风。角色早期木讷，V4 后才有完整表情。
- 玩家现有存档和设置不得被测试覆盖。当前本机玩家已有进度；所有测试使用独立存档。
- Godot MCP 插件是工作环境改动，保留。发行包不得带编辑器自动化服务。
- 付费资源制作已获用户授权；只有发现明确资源缺口时才调用，并记录实际作业与费用。

## 本轮交付与验收

1. 首次开饭逐步教拿盒、接菜、送桌；提示跟真实操作推进，支持鼠标、键盘、手柄。暂停、退出、继续不锁死。
2. AGI 结局可跳过、可重看；退出结局回到可继续游玩的技能树，保存与演出解耦。
3. 本地成就记录真实玩法里程碑，有可查看的清单，不冒充已经接通 Steam 平台成就。
4. 减少动态与顿帧开关、窗口尺寸选项；设置页在 1280×720 下可操作，所有选项有实际效果。震屏底层保留开关，但当前玩法未使用镜头震动，不把无作用的选项放进界面。
5. 修复存档备份恢复与异常数据边界；验证旧版迁移、重置、备份恢复、反复退款。
6. 生成独立 Windows 候选包，记录版本与校验结果，真实运行检查中英界面和关键输入。

## 协作接口

- `Game.achievements: Dictionary`：已获得成就 id → Unix 时间戳。
- `Game.achievement_catalog() -> Array`：条目含 `id`, `name`, `desc`, `group`。
- `Game.record_run(summary: Dictionary)`：结账后记录，键 `earned`, `eaten`, `caught`, `spilled`, `wasted`, `recipes`, `balance`, `grokked`, `trial`, `passed`, `full_boxes`。缺省键允许省略，真实数据才写。
- `Game.ending_seen: bool` 与 `Game.mark_ending_seen()`；`Game.ending_pending()` 判定已到 AGI 且未看结局。
- `Game.seen_buttons` 复用为首次提示持久化，不改变旧红点含义。
- `Settings.reduced_motion`, `Settings.screen_shake`, `Settings.hit_pause`，均为布尔值。
- 测试启动参数 `--test-profile=<name>` 使用独立进度，禁止写玩家设置。它不启用机器人。

## 玩家反馈补充范围 · 2026-10-19

本轮在上述基础上继续处理玩家报告，不冻结旧 demo 的交互和错误规则。保留 74 个非根升级节点与价格，修复金材质旧吸附、思考耗尽连发、品质落点/入盘可读性、鼠标跟手与扫掠接菜、失焦恢复；删除收益溢出扣款及其结算演出。统一今日菜单/招牌菜弹窗，重排技能贴纸并将盖章限定为满级。复用三个技能加入单品拼盘、余量缓存、换菜接力，规则与图鉴内说明一致。生成并实际接入同人设的大肥鱼 UI 插画。

补充验收：持续按住思考只启动一次、松手和冷却后能再启动；高速横移和低帧率食物过盒不得穿透；菜单重复打开不叠层；真实 GUI 输入不能穿透弹窗；有效菜单每档至少一道；构筑奖励真实送出时记账一次，帮手/幽灵不冒领；反复焦点通知后可恢复。合成通知测试不等于已复现所有第三方软件弹窗。
