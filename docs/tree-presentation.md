# 技能树、配餐与首局引导呈现重做

本分块只改 `tree_screen.gd`、`meal_planner.gd`、`run_coach.gd` 与专属测试/本说明。技能节点的原始数据坐标、价格、上限、解锁规则和 Game 接口保持不变。材质采用奶油纸、深海蓝和细黄铜线，去掉整屏放大的票券边框、满屏闪光和浮动长说明。

## 固定信息区域

技能树顶部固定预算、当前版本和工具栏；左侧是裁切的路线地图，右侧常驻完整技能名、等级、可滚动说明、前置路线、价格和购买/退款动作；底部单独放开饭与评测按钮。拖动或缩放不会让节点、连线侵入工具栏或详情区。点击节点只选中，明确的升级按钮或地图焦点下 Enter / A 才购买。选中路线高亮，满级节点用静态绿色纸面、勾号和小红章表示；长技能名的地图缩写可在侧栏读全。节点保持 172×108，避开数据中四对临界相邻节点，不改坐标。

节点使用已有 `canteen/ticket.png` 的细纸纹和穿孔，九宫格只拉伸空白中心，角点至多 12 逻辑像素；没有把票券放大成窗口边框。满级印章来自 `stamp.png`，只放在等级行右下空位，低于 85% 缩放隐藏，避免挤占小节点文字。路线地图仅取 `cork_bg.png` 内部软木区域并以 20% 透明度绘制，丢弃源图粗木框。详情等级行右侧增加 64×64 的食物/工具图标，按档口、饭盒、思考、营养、连击、品质等实际效果分组；完整技能名、说明滚动区、购买动作和字号没有缩减。所有图像复用已检查的现有资源，没有生成新素材或修改源图。

“当前进度”按钮把地图移到当前版本可继续升级的节点；方向键也会自动把选择移入地图。缩放范围 55%–150%，低缩放仅保留一行短名与等级。地图拖动在鼠标放开时结束，即使松开位置在工具栏上。

今日菜单/招牌菜改成两列宽行列表，菜图、菜名、档口和选择状态各自占区；右侧保留现有大尺寸角色主视觉及固定说明。删除厚底边和木框式卡片外观，不把人物立绘缩成菜品小图。既有单实例模式切换、选择原位更新、模态键盘阻挡、焦点闭环、关闭返回焦点和最后一道菜保护继续使用原接口。

首局引导改成左下角 1170×150 的清晰提示条，标题、设备对应主指令、计时规则与跳过按钮各自占区；缩短中英文句子，保留真实拿盒/接菜/送餐事件推进。手持饭盒进入左下提示区时，提示条根据实际饭盒素材边界移到上方，返回底部有 80 逻辑像素缓冲，避免边界附近反复跳动；不改鼠标范围或碰撞。实机复查发现跳过后的完成提示会回到底部遮住低位饭盒，现已修正为提示可见期间始终避让，并加入真实跳过按钮后的回归检查。

```powershell
& tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path game res://tests/tree_presentation_test.tscn -- --test-profile=tree_presentation_headless --lang=zh_CN
```

GPU 由根协调串行，使用相同场景去掉 `--headless`，追加 `--out=<绝对目录>`；`--small` 为 960×540，默认 1280×720；`--lang=en` 为英文。新文案须先由根合并 `docs/tree-presentation-translations.json`。`TREE_PRESENTATION_RESULT` 为机器可读结束标记，报告含关键源码 SHA256、引擎、语言、窗口尺寸和逐张截图哈希。测试中的后期进度、锁定状态和首局状态是明确夹具，不宣称是合法通关录像。

meal planner 的真实 GUI 行为检查通过 59 项（含新增手柄 A 单次升级和十字键保留地图焦点）；新增夹具 headless 通过 225 项，覆盖全部技能标题、详情与购买区不重叠，所有原始节点对无卡片交叠，地图不覆盖固定区，鼠标选中不扣款，Enter 只购买一次，满级/锁定/费用不足，所有菜品说明与状态行，以及首局设备提示、饭盒避让和真实跳过按钮。Headless 通过不能替代下面的实机结果。

## 实机评审

纸纹/图标初版在中文 1280×720、英文 960×540 headless 各通过 378 项，新增每个技能图标资源有效、状态文字与图标分离、完整标题及正文区域保留的检查；报告增加饭票、软木、印章及全部用到的分类图标 SHA256。最终 GPU 版进一步逐一验证替换素材后的 TextureRect 实际尺寸：技能图标 64×64、菜图 118×126、两种人物图 470×338，均没有被源图最小尺寸撑大。尺寸设置放在 add_child 后；票面及小图采用线性 mipmap 采样，避免最小窗口缩图锯齿。

最终材质版本在 NVIDIA RTX 4070 SUPER / Vulkan Forward+ 上串行完成四组：`zh720`、`zh540`、`en720`、`en540`，每组 504 项通过，退出码 0，无脚本或资源清理告警。每组 12 张原尺寸截图及报告位于 `build/qa/tree-presentation/<组名>/`；该目录是本地构建证据，不入发布资源。四组绑定同一份技能树/配餐/教学/测试源码，已覆盖先前布局版的证据。

已逐张查看最终 48 张截图：长说明首部与滚动到底部的解锁路径、节点部分等级/满级/锁定/费用不足、菜单与招牌双列、教学常规位置、左下极限饭盒避让和完成提示。四组均没有说明压住购买/开饭按钮、菜单详情盖确认按钮或教学盖饭盒/餐桌。饭票穿孔和纸纹保留，满级印章没有盖住名称/等级，详情图标与正文区分离。检查英文时发现长单词会留下单字母第二行，已改为省略显示。地图节点在最小窗口属于概览，完整名称和机制说明始终在固定侧栏；可用缩放按钮继续放大。

截图中的局内背景/HUD 是当时公共版本，只作为教学条对真实场景的遮挡证据；根随后还会整合独立局内 HUD。未做专业玩家主观评审，未把注入输入称为实体手柄手感测试。
