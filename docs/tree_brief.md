# 技能树重做：设计简报（2026-10-17）

给「技能树模型」讨论用。汇总了到目前为止和用户讨论定下的东西。技能树要推倒重做，这里的设定和原则保留。

## 游戏是什么
- 《吃白饭的大肥鱼》：免费、开源、非商用的粉丝向**短篇增量游戏**（参考 Nodebuster：一局一顿饭 → 回技能树升级 → 再来一顿；目标 1–1.5 小时打通，终点「实现 AGI」）。
- 一顿饭：食堂里章鱼梁阿姨从各档口的饭盆里把菜抛下来（每个档口固定出几种菜，菜基本垂直落下，下落速度因菜而异），玩家端着便当饭盒（2×2 → 2×3 → 2×4 格）左右上下移动接菜，接满送到饭桌；大肥鱼端着铁盆吃，吃一口给 token。饭点有时间限制（食堂关门就结束），没有吃饱上限。
- 饭盒里凑齐指定原料会**自动合成套餐**（占格更少，价值更高，套餐也能当原料继续合成 = 连锁）。
- 结算：基础 token × 倍率（现有：均衡倍率 = 主 : 荤 : 素 接近 4 : 3 : 3；流式输出 = 吃得越多越香；招牌菜）。
- 版本阶梯 V3 → R1 → V3.1 → V3.2 → … → AGI：每次「评测」= 一顿要赚到目标 token，交门票（目标的 10%），失败无惩罚。
- 外包：6 个原创 Q 版 AI 小助手（问问、谱谱、小G、克劳、双子、格格），各有不同技能，上班前排班（名额有限）。
- 详细现状见 docs/core_design_v4.md、docs/menu_design.md、game/data/menu.json（5 个档口、24 种菜、15 个套餐）、docs/fish_actions_design.md。上一版技能树草稿（要推倒重做）：scratchpad 里的 tree_design/index.html，或 https://claude.ai/artifact/HzHWGDhgTkuUKWzAWkvFjL。

## 用户定下的方向（最重要）
1. **两个极端流派 + 中间地带**，矛盾就是特色：
   - **暴食流**：极致混乱、量大、多多益善。满屏接、随机合成一堆低级套餐、大肥鱼一直在吃。可以有极致的随机天赋，比如「食材进入饭盒时随机变成高一级的另一种食材」。爽，挂机友好，但不可控。
   - **美食家流**：克制、憋个大的。像卡组精简：减少出菜种类和数量，提高单个菜的质量（菜品等级），追求饮食均衡，精心凑高级套餐和 combo。最极端时**一盒饭就能拿巨额收益**（乘区的魅力），「一道菜定胜负」。大肥鱼经常在**等**——**等待时间本身也可以是一个乘区**。
   - **中间流派**：在两个极端之间自然诞生，没那么极端也没那么爽，但更安逸、更稳定。
2. **美食家流要尽可能有深度**：菜有等级、套餐有等级、套餐有 combo；要能和暴食流博弈，所以**独特的乘区一定不能少**。
3. **不锁路线、不设反向节点**：任何节点都能点；每个节点只往一个方向加，不做「A 和 B 同时点就互相抵消」。取舍来自 token 有限（机会成本）和合成机制本身（暴食合成多但级别低，美食家合成少但级别高）。
4. **不教玩家玩**：游戏里不标流派；设计时心里有倾向，但要让「本来给暴食的天赋对美食家有意外增幅」这类跨流派联动自然发生。
5. **随时洗点**：两顿之间全额回滚；右键单个节点单独退款；构筑存档位。
6. 技能名多用 **AI 梗**（Skill、Agent、MCP、上下文窗口、KV Cache、MoE、思维链、流式输出、RLHF、Temperature、量化、蒸馏、RAG、Function Calling……），每个节点一句人话说明。
7. 增量游戏手感：一局内动作简单、屏幕越来越热闹；精细操作只能是一部分玩家的选择，不能是唯一出路；自动化（外包、自动推送 / 回收）是挂机层。

## 已经讨论过、方向认可的点子（可以用，也可以改）
- 套餐按原料数自动分级：一级小炒（2 样）、二级套餐（3 样）、三级大餐（4–5 样）、神级（6+ 或隐藏配方）。
- 菜品品级：普通 / 优质 / 金牌，乘进每口和套餐原料。
- 深度思考（R1 奖励）：底子只是慢放；「发散思维」（思考时大范围吸附）和「收敛思维」（思考时用不上的菜穿过饭盒）两个方向生长，都点就是「只吸需要的菜」。
- 招牌菜（开饭前选 2–3 道，对这道菜单独加成）；今日特价；三秒定律（地上的菜留几秒能捡）；美食评鉴（吃到不同种类的套餐叠倍率）。
