# 声音清单：什么时候响什么（2026-10-18）

反馈时说编号就行，比如「#19 太吵」「#33 听着怪」。「她」= 大肥鱼的嗓音（gen_voice.py 生成），「阿姨」= 梁阿姨的嗓音，其余是音效（gen_audio.py 生成）。百分比是触发几率：常见的时刻不是每次都出声。

## 混音（audio.gd 顶部有总线图）

- 大事件（version_up、ticket、trial_pass / trial_fail、shift_closed、peak_start）响的时候，其他音效和音乐压低 4dB，过后慢慢回来。
- 同一时刻只有一句嗓音（她和阿姨合起来算）：更要紧的先说，一样要紧就新的打断旧的；随口的（munch、wait 这类优先级 0）碰上别人在说话就不出声。
- 有人说话时音乐自动低 2–3dB；总线上有限幅器，很多声音一起响不破音。
- 试听页（声音收尾这一轮）：https://claude.ai/artifact/3A5BxfgCmpDdTUzrqyBZVu
