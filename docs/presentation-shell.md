# 标题与辅助界面的局部修整

本轮以 `30e97c7` 为视觉与结构基线，撤回整套深海蓝品牌区、设置左侧分类栏和宽账页。保留原暖食堂、手绘纸张、小黑板、木边、原位置的人物与飘落食物。用户指定的原画风与结构优先于新的主观风格选择。

仅保留可指出原因的改动：

- 标题把普通字体标题换成实际生成的中英文透明艺术字，仍在原左侧标题区。副标题和菜单向下避让新字标，存档信息允许换行。
- 设置完整恢复原横排四标签页，保留已有语言、焦点、保存和取消逻辑。
- 暂停恢复原暖色居中面板，只将提前结束操作改成准确的动作文字，避免英文使用过去时。
- 结局恢复原纸卡、暖光和角色结构，只把末页尾句移到角色下方，避免文字盖住衣裙。
- 结账恢复竖饭票、逐行打印、小红倍率标记、五个印章位和原结果章。饭票宽度由 620 增至 740 逻辑像素，说明列先预留金额与小红标记的宽度再换行；印章名最多两行。长发布/重试解释移到结果章下方的空处，避免压住返回按钮。保留减少动态立即完成、B/Esc 返回和关闭信号只发一次的修复。

定向场景为 `game/tests/presentation_shell_test.tscn`，需 `--test-profile=presentation_shell_*`。它覆盖艺术字资源、标题按钮边界、设置四页与键盘焦点、暂停内设置取消层级、结局翻页、密集饭票的返回按钮边界，以及合成手柄确认/取消输入。它不代替艺术审查、完整游玩或实体手柄验证。

恢复后中英文 headless 均通过，报告位于 `build/qa/presentation-shell/warm-headless-en/report.json` 和 `build/qa/presentation-shell/warm-headless-zh/report.json`。当前轮未占用 GPU；最终中英文、1280×720 与 960×540 视觉验证由主任务串行执行。此前深蓝设计截图已过时，不能作为本轮画风或小尺寸通过的证据；此前尝试的小尺寸实际上仍是 1280×720，主任务正在修正统一测试的尺寸参数与断言。
