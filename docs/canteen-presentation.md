# 保留手绘食堂的档口精修

2026-10-19。沿用原来的暖木色柜台、小黑板、右侧独立乘区牌和手绘对话框，不改变整体配色、玩法区域或既有掉落数值。

柜台原图定向编辑：去掉上方玻璃横梁与中间立柱，只保留两侧端柱；13个餐盘锚点沿用原坐标。梁阿姨画在柜台后面，脸部完整露出，下半身由台面遮挡。五个档口使用专门生成的中英文文字招牌；实际画面按档口宽度等比缩小并使用 mipmaps，去掉游玩画面的等级和勺子数量文字。图片来源与原始哈希见 `stall-art-provenance.json`。

每把实际工作的勺子对应一个圆环，环内显示该勺第一道菜；备菜完成后圆环变红，随后抛菜。同勺追加食材仍按实际权重随机抽取。详细触手分配、现有菜谱、占格、价值和解锁等级移到 **Esc 暂停 → 档口指南**；局内不再有 Tab 入口或覆盖柜台的透明点击区。

指南是暂停菜单的子面板。Esc / P / 手柄 B 先返回暂停菜单，恢复档口按钮焦点；再明确继续才恢复世界计时。它不会叠开，失焦不会额外创建暂停菜单，恢复后仍保留原输入防误触间隔。大肥鱼对话框右移，保留手绘气泡素材和朝向。
